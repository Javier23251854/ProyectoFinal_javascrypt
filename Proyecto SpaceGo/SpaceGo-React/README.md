# SpaceGo React

Esta aplicación React forma parte del proyecto SpaceGo y se sirve desde el mismo origen que Angular mediante el servidor Node.js de la carpeta principal.

Para ejecutar el proyecto completo, sigue las instrucciones del `README.md` ubicado en la carpeta principal. No ejecutes `npm run dev` para la presentación integrada: ese comando inicia Vite por separado.

La compilación de React se realiza desde la carpeta principal con `npm run build` o junto con Angular mediante `npm run preparar`.
